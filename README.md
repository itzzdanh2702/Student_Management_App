# EduManager - Student & Tuition Management

EduManager is a lightweight and user-friendly web application designed to help tutors and teaching centers efficiently manage classes, students, and lessons. It features attendance tracking, tuition payment management, revenue analytics, and secure real-time cloud data synchronization.

## 🌐 Live Demo
👉 **Try it out here:** [https://classes-management.netlify.app](https://classes-management.netlify.app)

## ✨ Key Features
- **Class & Student Management**: Easily organize students into classes and training sessions.
- **Attendance Tracking**: Keep track of student presence for each lesson (Present, Absent, Excused, Late).
- **Tuition Management**: Monitor payments, track unpaid balances, generate payment reminders, and export financial reports to Excel.
- **Multi-language Support**: Seamlessly switch between English and Vietnamese interfaces.
- **Cloud Synchronization**: Real-time database updates securely stored via Firebase.
- **Authentication**: Secure Login/Registration and Password Reset functionalities. Data is strictly isolated for each tutor/center account.

## 🛠 Tech Stack
- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Backend & Database**: Firebase (Authentication, Cloud Firestore)
- **External Libraries**: SheetJS, FileSaver.js (for Excel exports)
